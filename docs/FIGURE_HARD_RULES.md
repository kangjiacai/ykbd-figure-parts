# 抽卡小人 · 硬规则（B3 定稿）

不合理组合靠规则杜绝，不只修某一张样张。实现见 `js/figure-avatar.js` 的 `audit`（生成后断言，失败即报错）。

## 1. 绘制顺序（图层）

必须按此顺序，不可调换：

1. **身后披发**（可空；仅长发等需要落到身体后方的部分）
2. **身体**（腿、鞋、衣服、手臂）
3. **脖子**
4. **头**（含耳）
5. **发型一整套**（头顶 + 额前/发际同一套发块）
6. 五官

长发披肩须落在身体后面，禁止夹在「头与衣服之间」看起来像卡住。

## 1b. 发型一整套（不分刘海/头顶层）

- 每个发型画成**一整套完整发块**：头顶轮廓与额前/发际是同一 path（或同一组同色块）。
- **禁止**「前发/刘海一层盖额 + 头顶另一层」的分层结构（旧 `frontHair` + `backHair` 后脑勺椭圆）。
- 长发可以另有身后披发（`hairBehind`），但额前与头顶仍属 `hairSet` 同一套。
- 短发/寸头：一整顶，允许露额（按 short 规则）。

## 2. 可见脖子

- 任何发型都必须露出可见脖子。
- 身后披发可穿过脖子区域几何，但脖子在其后绘制；发型不得把脖子矩形完全盖住。
- 可见肤色段（头底→领口顶）约 **6–10px**（领口顶 y≈290；头底 y=282）；脖底仍插进领口（底 y=336），勿拔出。
- 断言：对脖子矩形采样，若被头发完全覆盖 → 报错。

## 3. 额头：按发型类型（不是绝对盖额）

每个发型必须在 `HAIR_TYPE` 中声明类型，未声明即报错。

| 类型 | 发型 | 规则 |
|---|---|---|
| `bangs` 盖额发际 | fringe、swept、long、bun | 发际盖额，下沿到眉上（额央 viewBox y≈158–170）；禁秃额。断言：额头带覆盖率 ≥0.70 且深度在 154–172 |
| `short` 短发 | spiky、curly、crop | **允许露额**，不强制额头覆盖率；仅禁止发际压到眉/眼（额央 y ≤172） |

- `crop`＝明显露额的短发变体（发际线额央 y≈120），额外断言覆盖率 ≤0.45，保证确实露额。
- 「秃额」只对 `bangs` 类成立；短发露额是正确画法，不是缺陷。

## 5. 身首拆分（头部 ≠ 衣领）

1. **头部部件** = 头 + 脖子肤色段；绝不连带任何衣领 / 帽兜颜色。
2. **身体部件** = 整件衣服，含完整衣领开口；衣领颜色与衣服同块统一（tee / hoodie / overall / jacket 皆然；jacket 白内领也属身体）。
3. 衣身顶部必须是 **U 形领口开口**（开口宽略大于脖子宽），禁止封闭横顶边；禁止 hoodie「身后拱起衣色领」。
4. 脖子底端伸进衣领开口 ≥20px（底约 y=330–338；可见肤色段约 6–10px）；图层：身后披发 → 身体 → 脖子 → 头 → 发型一整套。
5. 四肢与脖子锚点定在身体上（手接袖口、腿接裤腰、头–领口间距固定）。
6. 耳朵：豆形 + 淡内弧（禁止竖椭圆 + 竖缝）。

## 6. 适用范围

新增发型 / 改边路径 / 调图层时，必须仍通过上述断言；样张（B3 / B3b / B3c / B3d-short / B3e-bangs）只是种子示例，不是例外。
