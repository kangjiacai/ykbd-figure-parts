# B3 视觉气质参考

这是视觉气质和卡面构图的定稿参考。引擎输出要对齐这个精致度，不是旧 samples 那种简陋几何（方块眼、梯形衣、细棍腿）。

构图以最新的 `B3.png` 为准：黄绿斜贴卡里，小人必须整身居中、从头到鞋完整入框，不能贴底或裁脚。右侧是名字，右下是编码。不要参考已经被替换掉的裁切近景。

这些图只说明完成度和版式。本仓库样张仍走 `js/figure-avatar.js` 的种子切段，不会照搬参考图里的某一套部件。硬规则见 `docs/FIGURE_HARD_RULES.md`。
